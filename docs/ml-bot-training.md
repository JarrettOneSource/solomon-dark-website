# Learned bot training ownership

The accepted learned policy, inference, observations, action/choice controller
and admitted bot lifecycle are maintained in the separate Rust game repository.
They do not require the retired Website TypeScript rollout server.

Training migration is a separate development follow-up, documented with exact
reference revision and source paths in [Rust game cutover](RUST-GAME-CUTOVER.md#separate-training-migration-follow-up).
No training campaign or incomplete native rollout bridge is provided by this
Website cutover. Historical commands and measurements remain available in
Website commit `fa08ae249ff5563570bdb2a653e2ef9358ce7b83`.
