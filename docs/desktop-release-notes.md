## Solomon Darker desktop

The desktop packages the shared game client and a separate local authoritative
server. Solo play and local saves do not require the website. Use **Play with
friends** on the title screen to host an invitation or join a friend. All
players must have the same game build. The host must keep the app running.

Downloads: Windows x64 installer, macOS Apple Silicon disk image, and Linux
x64 AppImage. Linux users should mark the AppImage executable before launching.

The app checks for updates at launch. Downloading and restarting each require
confirmation. Offline launches and declined updates remain playable.

Local saves are separate from website cloud saves. Internet friend invitations
require the configured signaling service; some home networks additionally need
the operator's TURN relay. Hosting nearby improves regional latency but cannot
remove distance between players on different continents.
